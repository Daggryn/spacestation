PROCESS for Managing This Data:
Add Properties: Record new properties as we receive appraisals or other relevant information including style of property ‘modern’, ‘character’ ‘weatherboard’ block size etc. etc. Ensure all fields are filled out for completeness.
Tracking Follow-Ups: For every follow-up (whether via email, phone, or text), update the Last Follow-Up Date and note what happened in the Follow-Up Notes section. If there's a scheduled next action, fill out the Next Action Date.
Use Filters: Apply filters to track ongoing communications. You can filter properties by their Status to check for upcoming actions or those that need follow-up. This will allow you to sort by specific follow-up dates or status (like "SOLD," "Ongoing," or "Not Interested").
Set Calendar Reminders: Based on the Next Action Date, set automated reminders (would we need to do this via Google Calendar, Outlook, etc.) to ensure we do follow-up.
Review Regularly: Regularly review properties that need further contact or those marked as “Ongoing” to ensure nothing slips through the cracks. Maybe even colour-coded rows for better visibility (e.g., red for urgent follow-ups, yellow for medium priority, etc.).
